# Set Elsham ست الشام — Digital Menu

Static, mobile-first digital menu built from the supplied menu images.

## Files
- `index.html` — page structure and SEO metadata
- `style.css` — responsive UI
- `script.js` — menu data, search, category navigation and filtering
- `assets/` — logo and cropped food imagery extracted from the supplied menu

## Run
Open `index.html` in a browser or deploy the whole folder to any static host.

## Free deployment
This project is a static HTML/CSS/JavaScript site and can be deployed for free on GitHub Pages or Cloudflare Pages.

### Cloudflare Pages
1. Push the `shamcity-menu` folder to a GitHub repository.
2. In Cloudflare Dashboard choose Workers & Pages → Create application → Pages → Connect to Git.
3. Select the repository.
4. Framework preset: None. Build command: leave empty. Output directory: `/` (or the folder containing `index.html`).
5. Deploy.

The generated `*.pages.dev` URL can be used directly in the restaurant QR code.
