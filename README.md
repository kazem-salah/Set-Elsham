# Set Elsham ست الشام — Digital Menu

Static, mobile-first digital menu built from the supplied menu images.

## Files
- `index.html` — page structure and SEO metadata
- `style.css` — responsive UI
- `script.js` — menu data, search, category navigation and filtering
- `assets/` — logo and cropped food imagery extracted from the supplied menu

## Run
Open `index.html` in a browser or deploy the whole folder to any static host.
